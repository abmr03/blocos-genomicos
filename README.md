# Blocos Genômicos 3D - Materiais Pedagógicos

### Descrição

Este repositório contém os materiais pedagógicos desenvolvidos para a pesquisa "Aplicação de blocos genômicos tridimensionais no ensino de genética: relato de experiência pedagógica", realizada no Instituto de Aplicação Fernando Rodrigues da Silveira (CAp/UERJ).
A metodologia utiliza blocos genômicos impressos em 3D para tornar conceitos abstratos de genética em experiências concretas de aprendizagem, promovendo maior engajamento estudantil e compreensão conceitual no ensino médio.

### 📁 Conteúdo do Repositório

#### Roteiros de Aula
- **Roteiro Grupo Controle**: Instruções para atividades com representações bidimensionais
- **Roteiro Grupo Experimental**: Instruções para atividades com blocos genômicos 3D
  
#### Questionários de Avaliação
- **Questionário Grupo Controle**: Instrumento de coleta de percepções dos estudantes do grupo controle
- **Questionário Grupo Experimental**: Instrumento de coleta de percepções dos estudantes do grupo experimental

### 🎯 Objetivos dos Materiais
- Padronizar a aplicação da metodologia em diferentes turmas
- Facilitar a reprodução da experiência por outros educadores
- Fornecer instrumentos de avaliação das percepções estudantis
- Promover o ensino de conceitos de genética através de metodologias ativas

### 📚 Conceitos Abordados
- Genótipo e fenótipo
- Leis de Mendel
- Cruzamentos genéticos
- Meiose e crossing-over
- Formação de gametas
- Quadros de Punnett
- Variabilidade genética

### 🛠️ Como Utilizar
1. Baixe os roteiros apropriados para seu contexto (com ou sem blocos 3D)
2. Adapte as instruções conforme sua realidade escolar
3. Aplique os questionários para avaliar as percepções dos estudantes
4. Compare os resultados entre diferentes abordagens metodológicas
